1.V51C存在的一些问题
## 主要问题（按严重度）
### 1. B3 碳性误判 CC → 无限循环（核心问题，8 轮）
碳性电池 2635 被误判 LINEAR_LI（ty=6）→ CC → 16s 超时 ERROR → 重判 → 再 CC，全程循环 8 轮（08:03:16→08:04:00 不停反复）。 这就是 V54B 要修的问题 （CC_LOOP 锁定）。

### 2. ⚠️ B12 恒压锂被路由进 CC → 超时循环 → V54B 会永久拒充！
- B12 恒压锂 3034 换算 bat_mv≈1397 < 1520 → 被路由进 CC 而非 CV
- 恒压锂接近满电，CC 中电压 3034~3040 不升 → 16s 超时 → ERROR → 重判 → 再 CC，全程反复（08:03:30 CC→08:03:41 DET→08:03:48 CC→08:04:00 DET）
- 风险 ：V54B 的 CC_LOOP_MAX=2 锁定对 B12 同样生效——真恒压锂会在约 40s 后被 永久锁死拒充 [Linear Li ERR] 。这与上一轮我提醒的副作用一致，日志证实了 B12 确实反复进 CC。
### 3. 锂电 CV↔DET 反复（B4/B9/B10/B11）——V54B 未修
机制确认： CV 上爬检测 （ charge_mgr.c#L812-833 ）对所有类型生效——进 CV 后电压比起点基准再涨 ≥50 ADC 连续 N 帧 → ERROR → 重判 DET。真锂电进 CV 后电压仍缓慢爬升（恒压锂接近充满时斜率减小但不为 0），读数波动稍大就命中。

- B9 恒压锂：CV↔DET 反复 3 次（3448→3498 命中 ref+50 ）
- B10/B11/B4 各反复 2 次，每次重判中断充电重新检测
### 4. B5 恒压锂检测耗时 32 秒（DET 卡死）
B5 从 08:03:16 (ct=97) 卡 DET 到 08:03:48 才进 DIO，ct 累计到 487。期间电压 3480→3331→3483→3333→3571 大幅波动 ，稳定确认反复失败。期间 B5 不充电。

### 5. B6 线性锂 CV 电压异常跳变（3478↔2426）
B6 在 CV 中电压在 3478/3479/3476 与 2424/2417/2426 两组值之间跳变，疑似接触不良/串扰的 硬件问题 ，需检查 B6 电池触点。

### 6. ✅ 正确行为
B1 碱性、B2/B7 镍氢全部被正确拒充（[Dry/NiMH ERR]）；VCC 稳定 4645~4703mV；温度正常。
